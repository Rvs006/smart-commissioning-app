# v0.1.44 field acceptance checklist

- [ ] Record the approved site and scan authorization in the private record.
- [ ] Use the v0.1.44 unified portable EXE on a test machine with the official
      locally installed Nmap copy.
- [ ] As a global administrator, use **Approve detected Nmap** in IP Scanner
      and confirm that an engineer can select the approved TCP-connect scanner
      without completing a form.
- [ ] In a controlled concurrent test, submit two administrator approvals for
      the same installation and confirm both responses name one authority.
- [ ] In BACnet Foreign Device configuration, enter a valid IPv4 `address:port`
      endpoint and confirm that an explicit BBMD UDP Port overrides that port.
- [ ] From a sealed BACnet parent scan, create a property scan for one selected
      device and confirm that the child uses the parent transport.
- [ ] Confirm a BACnet request over 1,024 expected targets is rejected before
      a run begins.
- [ ] Perform the separately approved IP, BACnet, MQTT, and UDMI site tests and
      retain their private evidence. UDMI behavior is unchanged in v0.1.44.
- [ ] Record exact application commit, portable or image hash, run ID, and
      evidence-set ID.
- [ ] Generate condensed client and technical reports; verify payload manifest
      hashes and redaction.
- [ ] Scan the sanitized acceptance bundle for credentials and prohibited
      identifiers.
- [ ] Record acceptance-owner sign-off.

All rows remain open until recorded in the private field evidence store.
