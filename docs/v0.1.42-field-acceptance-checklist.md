# v0.1.42 field acceptance checklist

- [ ] Record the approved IP register filename, SHA-256, revision, and import ID.
- [ ] Run an IP Preview with a blank target editor and confirm the preview uses
      register addresses rather than returning an empty-target error.
- [ ] Save the site BACnet UDP port and interface. Preview, authorize, and run
      BACnet/IP; confirm the transport uses that port.
- [ ] Open **Points / Live Data** for a completed BACnet run. Record a device
      instance, point identifier, observed value, and unit from persisted data.
- [ ] Run a finite MQTT capture against the approved broker. Confirm a terminal
      run opens Results even if the live-topic refresh reports a temporary error.
- [ ] Record exact application commit, portable/image hash, run ID, and evidence-set ID.
- [ ] Generate condensed client and technical reports; verify payload manifest hashes and redaction.
- [ ] Scan the sanitized acceptance bundle for credentials and prohibited identifiers.
- [ ] Record acceptance-owner sign-off.

All rows remain open until recorded in the private field evidence store.
