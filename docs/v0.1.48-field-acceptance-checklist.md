# v0.1.48 field acceptance checklist

- [ ] Record the approved site and scan authorization in the private record.
- [ ] Use the v0.1.48 unified portable EXE on a test machine with the official
      locally installed Nmap copy, if the project uses Nmap.
- [ ] Complete an IP dry run with no existing authorization, then have a global
      administrator create the matching approval from Run Controls with the
      approved ticket, purpose, and scan window.
- [ ] Confirm the selected authorization permits only the matching sealed live
      request and that its live request contains no editable scan parameters.
- [ ] Confirm the portable visible version and `/api/v1/health` version both
      identify v0.1.48.
- [ ] Perform separately approved IP, BACnet, MQTT, and UDMI site tests and
      retain their private evidence. UDMI behavior is unchanged in v0.1.48.
- [ ] Record exact application commit, portable or image hash, run ID, and
      evidence-set ID.
- [ ] Generate condensed client and technical reports; verify payload manifest
      hashes and redaction.
- [ ] Record acceptance-owner sign-off.

All rows remain open until recorded in the private field evidence store.
