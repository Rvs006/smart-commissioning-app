# v0.1.42 release evidence manifest

Hash algorithm: SHA-256. Release source identity and artifact hashes are
recorded only after their generating commands complete. Private broker, register,
operator, and machine values are deliberately excluded.

Required final records: source commit; API/worker/frontend image IDs and
digests; portable EXE and ZIP path, size, and hash; approved register hash and
import identity; capture request/start/end; transport outcome; client and
technical report hashes; and independent collector reference.

The local real-broker synthetic case is evidence of release behaviour only. It
does not replace the approved long-window field evidence.
# Local build provenance

Any portable artifact built from a dirty worktree is non-publishable. Its
`BUILD_PROVENANCE.json` must report `source_commit: local-dirty-tree`,
`source_tree_state: dirty_local_non_publishable`, and `publishable: false`.
A release evidence pack requires a clean rebuild after the authorized release
commit before publication. Dirty local build records are diagnostic evidence,
not publishable provenance.
