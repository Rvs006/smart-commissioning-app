# v0.1.37 field baseline versus v0.1.40 candidate

The available v0.1.37 record described 780 assets and 2,340 payload families.
v0.1.40 restores that blank-applicability contract: blank Payload type and
applicability yield state, metadata, and pointset, while invalid explicit values
remain invalid. Expected-topic traffic marks a registered asset observed even
when payload content is malformed; wrong-topic and unexpected traffic remain
separate.

The v0.1.39 regression stopped a finite run after diagnostic retention filled,
then reported success as `window_elapsed`. v0.1.40 makes the transport outcome
the source of truth, retains latest expected evidence separately, and permits
diagnostic truncation without ending the requested window.

No new production ten-hour field run has been executed. Counts, cadence, and
acceptance remain unclaimed until the owner-approved field test completes.
