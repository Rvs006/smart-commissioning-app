# v0.1.39 field acceptance checklist

This checklist keeps application acceptance separate from publisher and field
acceptance. A successful report job, Docker build, or automated Compose run is
not a field pass.

## Frozen contract

| Record | Value |
| --- | --- |
| Canonical register file and SHA-256 | `<REGISTER_FILE> / <REGISTER_SHA256>` |
| Register revision and import identity | `<REGISTER_REVISION> / <IMPORT_ID>` |
| Expected asset count | `<OWNER_APPROVED_COUNT>` |
| Approved applicability matrix | `<APPROVED_APPLICABILITY>` |
| Approved scope | `<APPROVED_SCOPE>` |
| Application commit | `<40_CHARACTER_COMMIT>` |
| Evidence-set ID | `<EVIDENCE_SET_ID>` |
| Gate A run ID | `<GATE_A_RUN_ID>` |
| Gate B run ID | `<GATE_B_RUN_ID>` |
| Operator, machine, broker references | `<OPERATOR_REF> / <MACHINE_REF> / <BROKER_REF>` |

Keep the actual register, credentials, broker commands, and device details in
the approved private field workspace. Public evidence may contain only the
sanitized references and hashes.

## Gate A: full-register scale

- [ ] Use the exact owner-approved register and one approved, unfiltered scope.
- [ ] Load the pre-run manifest and reject a different register, scope,
  application commit, import identity, or applicability matrix.
- [ ] Record paired application and independent append-only evidence with the
  same run ID and evidence-set ID.
- [ ] Reconcile each registered asset as expected-topic, alternate-topic,
  wrong-topic, no-match, or missing. Keep unexpected publishers outside
  registered metrics.
- [ ] Generate client and technical products whose scope, register identity,
  run identity, and evidence-set ID match the manifest.
- [ ] Hash every retained artifact and run the credential/prohibited-identifier
  scan over the complete sanitized bundle.

## Gate B: completed capture window

- [ ] Run the complete required cadence, documented by the acceptance owner.
- [ ] Pass only with `window_completed=true` and
  `termination_reason=window_elapsed`.
- [ ] Fail explicitly for cancellation, broker interruption, message or
  resource caps, disk failure, truncated JSONL, or any partial evidence.
- [ ] Keep stale, silent, malformed, schema-invalid, wrong-topic,
  alternate-topic, unresolved-applicability, and unexpected results separate.
- [ ] Preserve Gate A evidence and compare final hashes without overwriting it.

## Application gate

- [ ] Missing values remain distinct from received `0` and `false`.
- [ ] Raw evidence is redacted, bounded, deterministic, and retrievable from a
  clean-machine technical ZIP.
- [ ] Every finding has an explicit mismatch value and a finding-to-evidence
  mapping status.
- [ ] A selected-report bundle contains `report_set_manifest.json` with member
  hashes and evidence-set IDs.
- [ ] Portable and Docker artifacts expose the same release version and source
  commit as the release evidence.

Field acceptance remains open until both gates pass and the acceptance owner
records approval. No row in this repository claims that the field gates passed.
