# v0.1.52 release evidence manifest

Hash algorithm: SHA-256. Record release source identity and artifact hashes only
after the generating commands complete. Private network, machine, operator, and
commissioning data are deliberately excluded.

Required final records: source commit; API, worker, and frontend image IDs and
digests; portable EXE and ZIP path, size, and hash; migration head; Brief and
Learning content gate; browser interaction and layout gate; approved
authorization; run and evidence-set IDs; client and technical report hashes;
and owner sign-off.

## Local build provenance

Any portable artifact built from a dirty worktree is non-publishable. Its
`BUILD_PROVENANCE.json` must report `source_commit: local-dirty-tree`,
`source_tree_state: dirty_local_non_publishable`, and `publishable: false`.
A release evidence pack requires a clean rebuild after the authorized release
commit before publication. Dirty local build records are diagnostic evidence,
not publishable provenance.
